# 手机号登录配置指南（P2-5）

> 前端代码已完成（Auth 页「手机登录」tab：发送验证码 → 验证码登录）。
> 后端需要以下配置才可真正收发短信。

## 1. 启用 Phone 认证提供商

Supabase Dashboard → **Authentication → Providers → Phone**：

1. 开启 **Enable Phone Signup**
2. 选择短信服务商并配置密钥：

| 服务商 | 适用地区 | 配置项 |
|--------|---------|--------|
| Twilio | 海外 | Account SID / Auth Token / 发信号码 |
| Vonage (Nexmo) | 海外 | API Key / API Secret / Brand |
| MessageBird | 海外 | API Key / Originator |
| 国内短信（阿里云/腾讯云） | 中国大陆 | 需通过 Supabase 自托管或 SMS 网关中转 |

3. 点击 **Save**。

## 2. 国内短信方案说明

Supabase 托管版内置短信服务商以海外为主（Twilio 等），**中国大陆手机号建议**：

- **方案 A**：使用支持中国短信的网关（如通过 Twilio 中国通道，费用较高）
- **方案 B**：自托管 Supabase，配置国内短信服务商（阿里云短信 / 腾讯云 SMS）
- **方案 C（推荐起步）**：保持邮箱登录为主，手机号作为「绑定信息」展示与家长联系用（当前 Profile 页已支持编辑手机号）

## 3. 验证码参数（可选）

Dashboard → **Authentication → Phone**：

- **OTP Length**：验证码位数（默认 6）
- **Max Frequency**：同一号码发送频率限制（默认 60s）
- **SMSTemplate**：自定义短信模板，默认含 `{{ .Code }}` 与 `{{ .Expiration }}`

## 4. 前端流程说明

```
用户输入手机号 → signInWithOtp({ phone }) 发送验证码
→ 用户输入验证码 → verifyOtp({ phone, token, type: 'sms' }) 建立会话
→ 登录成功（新手机号自动创建账号）
```

- 新手机号首次登录会自动注册账号（role 默认 child，可在注册后由家长调整）
- 手机号与邮箱账号是**独立账号**，如需绑定请通过 Profile 页编辑手机号

## 5. 验证

1. 用真实手机号发送验证码
2. 查看短信是否收到（注意测试环境可能延迟）
3. 输入验证码完成登录
